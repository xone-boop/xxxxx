# PrimeClick Digital Agency

Modern, high-performance website for PrimeClick Performance Marketing and Growth Agency.

### Tech Stack

- React 18
- React Router 7
- Vite 6
- Vanilla CSS with Design System Tokens

### Project Structure

- src/pages: Application pages (Home, Services, CaseStudies, Calculator, Contact)
- src/components: Reusable components (Navbar, Footer)
- src/index.css: Global dark theme design tokens and styles
- docs: Page screenshots and documentation archive

### Getting Started

Install dependencies:

```bash
npm install
```

Start development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview production build:

```bash
npm run preview
```

### Deployment

This project is configured as a standard Single Page Application (SPA) ready to be deployed on platforms such as Vercel, Netlify, or Cloudflare Pages.
